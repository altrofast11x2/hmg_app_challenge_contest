# 시연 시나리오 (2분 30초)

화면 세 개를 나란히 띄운다: **에뮬레이터**(Pleos Connect) · **Virtual Console**(차량 상태) · **관리자 웹**.
녹화는 팀이 OBS로 한다. 에뮬레이터 화면만 따로 녹화할 때는 README의 개발자 메모(`adb shell screenrecord`)를 쓴다.

## 장면별 표

| 시간 | 화면 | 조작 | 자막 | 숏폼 |
|---|---|---|---|---|
| 0:00–0:15 | 종이 운행기록부 사진 또는 엑셀 화면 (팀이 직접 만든 자료) | 없음 | 업무용 차를 쓰면 운행기록부를 써야 합니다. 하지만 매번 계기판을 보고 적는 사람은 거의 없습니다. 월말에 몰아 쓰고, 회사는 믿기 어렵습니다. | **Spot** |
| 0:15–0:30 | 관리자 웹 › 차량 | **연결 코드 발급** → 6자리 코드 표시 | 관리자는 웹에서 차량 연결 코드를 한 번 발급합니다. | |
| 0:30–0:45 | 에뮬레이터 (P 상태) | 앱 실행 → 연결 화면에서 코드 6자리 입력 → "AltroStudio 데모에 연결됐어요" | 차가 서 있을 때 숫자 6자리만 누르면 회사에 연결됩니다. 비밀번호는 없습니다. | |
| 0:45–1:10 | Virtual Console → 에뮬레이터 | 기어 **D** → 주행 화면으로 바뀜 → 계기판 거리 늘리기 | 기어를 넣으면 기록이 자동으로 시작됩니다. 주행 중에는 화면에 누를 것이 없습니다. 거리는 차의 계기판 값을 그대로 씁니다. | **Scene** |
| 1:10–1:30 | Virtual Console → 에뮬레이터 | 기어 **P** → 분류 화면 → **일반업무** 한 번 누르기 | 차를 세우면 용도만 한 번 고릅니다. 같은 목적지는 지난번 분류를 먼저 제안합니다. | **Solve** |
| 1:30–1:45 | 에뮬레이터 | 홈 → **월별 운행기록부** → 무결성 표시 | 국세청 서식 그대로 월별 운행기록부가 채워집니다. 기록은 해시 체인으로 묶여 고친 흔적이 남습니다. | |
| 1:45–2:05 | 관리자 웹 › 운행기록부 | 새로 고침 → 방금 운행 확인 → 업무사용비율 → **CSV 내려받기** → Excel로 열기 | 회사는 모든 차량의 기록을 바로 받아 봅니다. CSV를 그대로 정산에 씁니다. | |
| 2:05–2:30 | 정리 화면 (`docs/sdk-usage.md` 표를 옮긴 슬라이드) | 없음 | Pleos Vehicle SDK의 계기판 거리·차량 식별·배터리, NaviHelper의 주소와 목적지, 차량 주행 상태로 만든 앱입니다. 차가 직접 쓰는 운행기록부, 자동 운행기록부. | |

비업무 운행을 보여 주려면 1:10 장면에서 **비업무**를 고르고, 기록부에서 주소 없이 거리만 남은 것을 보여 준다.

## Virtual Console 조작 (브라우저 대신 명령으로도 가능)

```bash
adb forward tcp:8088 tcp:8088
curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Drive"
curl -X PUT "http://127.0.0.1:8088/vehicle/odometer?traveled_distance_km=12.3"
curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Park"
```

## 숏폼용 장면 (30초~1분 세로 영상)

| 표시 | 장면 | 쓰는 구간 |
|---|---|---|
