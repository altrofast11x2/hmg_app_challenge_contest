# A01 첫 실행 개인정보 동의

> 정차 중 전용 · 목업 `mockups/A01-A03.html#A01` · 공통 규칙 `A00-common.md`

## 목적
수집 항목, 목적, 보유기간, 거부할 권리를 보여 주고 **"동의하고 시작" 버튼을 누른 경우에만** 동의로 저장한다.

## 동의로 처리하지 않는 것
뒤로가기, 빈 곳 터치, 앱 전환, 홈 버튼, 화면 꺼짐, "동의하지 않음". → 동의 기록 없음, 데이터 수집 안 함, 다음 실행 때 다시 A01.

## Portrait (900×1224)
- TopBar 동일 (단계 칩 유지)
- 앱 표시 + 요약 3줄 → 동의 카드 5개 (전체 세로 스크롤)
- **하단 고정 영역**(스크롤 안 됨): 배경 `drivelog_background`, 위 테두리 `drivelog_border` 2, 안쪽 여백 32/40. "동의하고 시작"(120) 위, "동의하지 않음"(96) 아래, 사이 16
- 스크롤 영역 아래 끝에 하단 고정 영역 높이만큼 여백

## 문구 (확정 전 항목은 [ ] 표시)

**① 수집하는 정보**
- 주행거리 — 운행 전·후 계기판 누적거리 (차량에서 직접 읽음)
- 운행 시각 — 시작·종료 시각
- 업무 운행의 출발·도착지 — 주소 (업무 운행만)
- 배터리 잔량 — 운행 전·후 (%)
- 차량 식별 — 차대번호(VIN). 확인되지 않으면 앱이 만든 기기 ID
- 운행 용도 — 출퇴근 / 일반업무 / 비업무 (직접 선택)

**② 수집하지 않는 정보**
- 실시간 위치와 이동 경로
- 비업무 운행의 주소 (거리만 기록)
- 주행 속도

**③ 이용 목적**
- 업무용 승용차 운행기록부 작성
- 소속 조직 관리자와 지정된 회계·세무 담당자의 열람

**④ 보유기간**
- [보유기간 — 기획 확정 필요. 세무 증빙 보존기간과 맞출 것]
- 동의를 철회하면 이 차량에 저장된 기록을 즉시 삭제

**⑤ 거부할 권리**
- 동의하지 않아도 됩니다. 동의하지 않으면 자동 기록 기능을 쓸 수 없어요.

## 상태

| 상태 | 표현 |
|---|---|
| 기본 | 위와 같음. "동의하고 시작" 활성 (끝까지 스크롤 강제 안 함 — 운전석 조작 부담 감소) |
| 누름 | A00 3.2 |
| 저장 중 | "동의하고 시작" 로딩. 로컬 저장이라 보통 즉시 → A02 |
| 저장 실패 | 버튼 위 오류 배너: 배경 `drivelog_status_error_container`, 글자 `drivelog_status_error`, "저장하지 못했어요. 다시 눌러 주세요" |
| "동의하지 않음" | 같은 화면에서 확인 영역으로 교체(모달 아님): "동의하지 않으면 운행이 기록되지 않아요" + [돌아가기](Primary) [앱 닫기](Secondary). 앱 닫기 = `finish()` |

## 주행 중 / 정차 중
- 정차 중(P): 위 화면
- **주행 중**: A04 주행 중 화면의 "시작 전" 변형으로 교체 — 큰 글자 "정차 후 시작할 수 있어요" (`drivelog_headline`), 터치 요소 없음. 동의 내용 숨김. 기록하지 않음
- 다시 P → A01 처음 상태(스크롤 맨 위)

## 저장 값
`consentVersion`(문구 버전, 예 "2026-10-26"), `consentedAt`(시각). 문구가 바뀌면 버전을 올리고 다시 동의 받는다.
