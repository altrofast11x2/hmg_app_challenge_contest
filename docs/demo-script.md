# 시연 시나리오 (약 3분 30초, 0.3.1)

화면 세 개를 나란히 띄운다: **에뮬레이터**(Pleos Connect) · **Virtual Console**(차량 상태) · **관리자 웹**.
녹화는 팀이 OBS로 한다. 에뮬레이터 화면만 따로 녹화할 때는 README의 개발자 메모(`adb shell screenrecord`)를 쓴다.

## Virtual Console 조작 (브라우저 대신 명령으로도 가능)

브라우저 없이 명령으로 쓸 때는 Virtual Console이 차량 값을 받도록 1초마다 접속 신호(`curl -X POST "http://127.0.0.1:8088/browser/session?client=demo"`)를 보내 둔다.

```bash
adb forward tcp:8088 tcp:8088
curl -X PUT "http://127.0.0.1:8088/vehicle/body?window_rl=60"        # 뒷좌석 왼쪽 창문 열기 (하차 점검)
curl -X PUT "http://127.0.0.1:8088/vehicle/body?cabin_light=true"    # 실내등 켜기
curl -X PUT "http://127.0.0.1:8088/vehicle/ev-battery?field=soc&value=18"  # 배터리 18%
curl -X PUT "http://127.0.0.1:8088/vehicle/hvac?driver_temp=23"      # 주행 중 운전자가 온도를 바꾼 상황 (정차 때 맞춤 설정으로 기억)
curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Drive"
curl -X PUT "http://127.0.0.1:8088/vehicle/odometer?traveled_distance_km=12.3"
curl -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Park"
```
